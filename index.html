Suppression de compte

MaRoue — Gérez vos données personnelles

Comment supprimer votre compte ?

Vous pouvez demander la suppression de votre compte MaRoue et des données personnelles qui lui sont associées.

Depuis l’application

  1. Ouvrez l’application MaRoue.
  2. Connectez-vous au compte concerné.
  3. Ouvrez la rubrique de votre compte ou de votre profil.
  4. Appuyez sur « Supprimer mon compte » si cette option est disponible.
  5. Suivez les instructions de confirmation affichées.

La suppression est définitive lorsqu’elle a été exécutée. Sauvegardez au préalable les informations que vous souhaitez conserver.

Vous n’avez plus accès à l’application ?

Vous pouvez contacter l’assistance par e-mail pour demander la suppression de votre compte. Indiquez l’adresse e-mail associée à votre compte MaRoue.

Demander la suppression par e-mail

Quelles données sont concernées ?

La demande vise la suppression du compte utilisateur et des données personnelles qui lui sont associées, dans la mesure où leur suppression est applicable.

Selon les fonctionnalités effectivement utilisées dans MaRoue, ces données peuvent comprendre :

  • Les informations du compte, notamment l’adresse e-mail ;
  • Les données de profil associées au compte ;
  • Les données personnelles enregistrées dans le cadre de l’utilisation de l’application.

Les données conservées uniquement sur votre appareil peuvent nécessiter une suppression locale ou la désinstallation de l’application. La désinstallation seule ne garantit pas la suppression des données stockées sur les serveurs.

Délais et conservation des données

Chaque demande doit être examinée et traitée dans un délai raisonnable, conformément aux obligations légales applicables.

Certaines informations peuvent devoir être conservées pendant une durée limitée lorsque la loi l’impose ou autorise leur conservation, par exemple pour répondre à une obligation légale ou résoudre un litige. Dans ce cas, seules les données nécessaires doivent être conservées pendant la durée applicable.
